# كشافة الرسالة الإسلامية

A web-based management system for organizing scout branches, leaders, members, activities, and meetings.

## Features

### Admin Dashboard

* Add and manage leaders
* Manage members associated with each leader
* Create, edit, and manage meetings
* View and manage personal information
* Trash for managing deleted leaders and members

### Leader Dashboard

* Add and manage members
* Create and manage activities
* Track activity attendance and see who attended
* View and manage personal information
* Trash for managing deleted members

## Technologies

* HTML
* CSS
* JavaScript
* Supabase
* SQL
